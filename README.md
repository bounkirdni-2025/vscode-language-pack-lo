# ແພັກເກດພາສາລາວສຳລັບ VS Code (Lao Language Pack for Visual Studio Code) 🇱🇦

ແພັກເກດພາສາລາວ ມອບປະສົບການການໃຊ້ງານສ່ວນຕິດຕໍ່ຜູ້ໃຊ້ (UI) ເປັນພາສາລາວຢ່າງເຕັມຮູບແບບສຳລັບ Visual Studio Code ເພື່ອຊ່ວຍໃຫ້ນັກພັດທະນາ ແລະ ນັກຮຽນ-ນັກສຶກສາລາວ ເຂົ້າເຖິງການຂຽນ Code ໄດ້ງ່າຍຂຶ້ນ.

## ວິທີນຳໃຊ້ (Usage)

ທ່ານສາມາດປ່ຽນພາສາເລີ່ມຕົ້ນຂອງ VS Code ໃຫ້ເປັນພາສາລາວໄດ້ງ່າຍໆ ໂດຍໃຊ້ຄຳສັ່ງ **Configure Display Language**:

1. ກົດປຸ່ມ `Ctrl+Shift+P` (ຫຼື `Cmd+Shift+P` ສຳລັບ macOS) ເພື່ອເປີດ **Command Palette**.
2. ພິມຄຳວ່າ `display` ແລ້ວເລືອກຄຳສັ່ງ **Configure Display Language**.
3. ເລືອກພາສາ **`Lao (ພາສາລາວ)`** ຈາກລາຍຊື່ພາສາທີ່ຕິດຕັ້ງແລ້ວ.
4. ກົດ **Restart** ໂປຣແກຣມ ເພື່ອເລີ່ມຕົ້ນໃຊ້ງານພາສາລາວໄດ້ທັນທີ!

ສຳລັບຂໍ້ມູນເພີ່ມເຕີມ ສາມາດເບິ່ງໄດ້ທີ່ [ເອກະສານທາງການຂອງ VS Code](https://go.microsoft.com/fwlink/?LinkId=761051).

# Lao Language Pack for Visual Studio Code 🇱🇦

The Lao Language Pack provides a localized UI experience for Visual Studio Code, empowering the Lao developer community and students to code with ease.

## Usage

You can override the default UI language by explicitly setting the VS Code display language using the **Configure Display Language** command:

1. Press `Ctrl+Shift+P` (or `Cmd+Shift+P` on macOS) to bring up the **Command Palette**, then type `display` to filter and select the **Configure Display Language** command.
2. Select **`Lao (ພາສາລາວ)`** from the list of installed languages.
3. Restart VS Code to apply the changes.

See [Docs](https://go.microsoft.com/fwlink/?LinkId=761051) for more information.
